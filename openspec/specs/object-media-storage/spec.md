# object-media-storage Specification

## Purpose

Хранить оригиналы и immutable display derivatives в приватном объектном хранилище RustFS, используя ограниченный локальный кэш только для ускорения выдачи и обработки.

## Requirements

### Requirement: RustFS является долговечным source of truth для медиа
Система SHALL сохранять принятые оригиналы и созданные derivatives в приватном S3-compatible bucket RustFS. Каждый объект MUST иметь непрозрачный неизменяемый ключ и MUST NOT зависеть от имени файла, переданного пользователем, или локального пути сервера.

#### Scenario: Загрузка медиа принята
- **WHEN** администратор успешно завершает допустимую загрузку
- **THEN** оригинал фиксируется как приватный объект RustFS со сгенерированным сервером неизменяемым ключом

### Requirement: Оригинал нельзя получить публично
Система MUST NOT раскрывать анонимным клиентам оригиналы, ключи объектов, учётные данные RustFS или публичный список bucket. Перед выдачей derivative публичный media-запрос MUST проверяться по текущему состоянию публикации галереи.

#### Scenario: Анонимный посетитель запрашивает путь к оригиналу
- **WHEN** анонимный посетитель пытается получить оригинал или raw storage key
- **THEN** система отклоняет запрос, не раскрывая существование объекта

### Requirement: Локальный кэш ограничен и не является источником истины
Система SHALL использовать локальный кэш только для доступных derivatives и временных файлов обработки. Она MUST соблюдать настроенный лимит ёмкости, вытеснять наименее давно использованные записи до превышения лимита и восстанавливать отсутствующую запись кэша из RustFS. Потеря кэша MUST NOT приводить к потере долговечного медиа.

#### Scenario: Кэшированный derivative был вытеснен
- **WHEN** посетитель запрашивает готовый derivative, отсутствующий в локальном кэше
- **THEN** система получает его из RustFS, выдаёт посетителю и возвращает в кэш, только если это допускает лимит

### Requirement: Браузер получает ограниченные полномочия загрузки объекта
Система SHALL выдавать полномочие на загрузку только аутентифицированному администратору, для одного непрозрачного upload key и на короткий настроенный срок. Система MUST проверить завершённый объект до создания записи медиа или постановки обработки.

#### Scenario: Полномочие загрузки истекло
- **WHEN** администратор пытается использовать истёкший upload URL
- **THEN** загрузка объекта отклоняется, и никакая запись медиа не становится готовой
